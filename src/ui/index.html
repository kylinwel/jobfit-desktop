BOSS 支持已建立的会话；牛客支持站内申请，官网网申需手动处理。使用平台已有简历，每分钟最多一项、每天最多五次；结果未验证时暂停且不重试。平台适配尚需你的登录账号实测。

操作记录

每日岗位表

读取公开岗位，在本机按已保存的简历资料匹配；保留得分 ≥ 60 且没有硬性条件冲突的新发岗位。

匹配分 ≥ 60

JobFit 打开时定时运行，错过后下次打开补跑。不会自动投递；表格以 CSV 保存，可用 Excel 打开。BOSS 只读取已打开的平台页面。

尚未启用

招聘平台账号

在独立平台窗口中登录，登录会话只保存在本机。密码与验证码由你直接在平台输入。

牛客投递简历

先在牛客上传或完善简历，再填写其准确名称。队列会选择并核对这个名称；这里生成的岗位专属简历仍需先手动上传到平台。

打开岗位 → 采集当前页 → 生成并审核简历 → 到沟通记录启动队列。牛客岗位列表用于初筛，投递前请打开并采集完整详情。登录过期、验证码和需要补填的信息会交给你处理。

模型连接

默认使用岗位关键词整理经历。配置模型后，也可以按岗位要求挑选相关经历。

调用时会向你配置的端点发送岗位描述和已确认项目素材，不发送联系信息字段。素材文本里如有个人信息，也会随文本发送。密钥仅存本机，未加密。
