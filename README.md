# JobFit · 本机求职工作台

[English](README.en.md) · [使用指南](docs/usage.md) · [架构](docs/architecture.md) · [参与贡献](CONTRIBUTING.md)

把岗位筛选、真实经历、岗位简历和每日岗位表放到一个桌面应用里。优先支持 BOSS 直聘与牛客网，资料与登录会话保存在本机。

**0.1.0 是早期版本。** 匹配、简历、日报和队列状态经过自动化测试；平台发送适配尚未用真实登录账号完成端到端验证。建议先演练，并检查首个真实岗位的结果。

## 能做什么

| 功能 | 当前实现 |
| --- | --- |
| 岗位匹配 | 按城市、毕业届别、学历、实习时长、每周出勤和技能比较条件，显示冲突、差距和待确认项 |
| 岗位简历 | 从已确认的项目事实中选择和排序，导出 Markdown、HTML，打印 / 另存 PDF |
| 可选模型 | 兼容 Chat Completions 接口，只返回真实素材引用，不直接编造简历正文 |
| 平台账号 | BOSS、牛客各自使用独立的持久登录窗口，登录和验证码由本人处理 |
| 岗位采集 | 读取平台窗口当前页面的列表、详情或 BOSS 会话；也可手动粘贴 JD |
| 岗位日报 | 分页读取牛客公开实习 / 校招岗位，在本机评分；保留 ≥60 分且无硬性冲突的新发岗位 |
| CSV 与通知 | 日报带公司、岗位、匹配理由与投递链接；可设置北京时间每日 09:00 整理及桌面通知 |
| 受控队列 | 岗位逐项审核后执行，支持演练、暂停、去重和中断恢复；结果不确定时暂停 |

匹配分是可解释规则的排序结果，**不表示录取概率或公司质量**。岗位创建时间与刷新时间分开处理；发布时间无法核实的岗位会单列。

## 快速开始

需要 **Node.js 24+、npm**。主要在 Windows 环境验证；其他系统的原生通知、登录与打包尚待验证。

```bash
git clone https://github.com/kylinwel/jobfit-desktop.git
cd jobfit-desktop
npm ci
npm start
```

首次打开后：

1. 在「真实经历」填写自己的背景、意向条件和实际参与的项目；勾选符合事实的项目素材。
2. 在「平台账号」打开 BOSS 或牛客并自行登录，在平台内搜索岗位，再采集当前页。
3. 检查匹配分析，生成岗位简历，按需导出。
4. 在「岗位日报」保存每日时间并启用通知，也可点击「立即整理」。
5. 投递前核对平台已有简历和队列；先启动演练，再决定是否执行真实发送。

应用保持运行时才会定时整理，最小化可继续；完全退出或关机时停止，下次打开后补跑。定时功能默认关闭，个人资料为空。

## 平台支持边界

- **BOSS**：支持当前页面采集，以及已建立会话的招呼和平台当前在线简历发送。首次沟通需在平台完成，再采集对应会话。日报只读取已打开页面。
- **牛客**：支持公开岗位日报、列表 / 详情采集和可唯一识别的站内申请。队列使用在设置中指定名称的已有平台简历；企业官网网申、官网闪投绑定、补填信息需手动处理。
- 每岗位专属 PDF 需要先自行上传到平台；生成简历不等于附件已发送。
- 每分钟最多执行一项，每日最多五次尝试。资料、岗位或平台简历名称变更后需重新审核。
- 页面变化、登录过期、验证码、访问限制或无法验证提交结果时会停止，避免自动重试。

## 数据和隐私

用户目录由系统决定。Windows 默认位于 `%APPDATA%/JobFitDesktop`，可点击「数据目录」打开。

- 简历、岗位、历史记录与登录会话保存在本机，不写入源码目录。
- 日报的公开请求只带页码、数量和岗位类别；简历和意向城市在本机处理。
- 显式点击模型选材时，会向所配置端点发送岗位与已确认项目素材，不发送独立的姓名、电话或邮箱字段；素材文本里已有的信息仍会随文本发送。
- **模型密钥当前以明文保存在本机资料文件中**，备份导出会去除密钥。请保护用户目录。
- 仓库只包含源码和虚构示例；请勿提交真实简历、Cookie、备份或密钥。

## 开发与打包

```bash
npm run check
npm test
npm run pack     # 生成未安装的桌面程序目录
npm run dist     # 在 Windows 上生成 NSIS 和便携版
```

打包结果位于 `dist/`。当前未配置代码签名，发布安装包前应自行检查来源和签名配置。CI 运行语法、发布范围检查及离线测试，不连接招聘账号、不发送简历。

```text
src/main/       Electron 入口、平台窗口、本地存储、投递服务与定时日报
src/ui/         原生 HTML / CSS / JavaScript 界面与匹配逻辑
tests/          条件筛选、事实保持、平台 DOM、队列、日报与原生边界测试
scripts/        语法及发布范围检查
```
